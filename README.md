# Assignment 2 – 2D Roguelike Game

## Chosen Option
Option 1: 2D Roguelike Game

## Description
This is a turn-based 2D roguelike game made with Unity 6.3.

The player explores a randomly generated board, collects food, destroys walls, avoids enemies,
and reaches the exit to continue to the next level

## Controls
- Arrow keys: Move
- R:restart after Game Over

## Main Features
- Procedural 8x8 board generation
- Random ground and wall tiles
- Food resource system
- Small and large food items
- Walls with health
- Turn-based enemy movement and attacks
- Exit and level progression
- Game Over state
- Smooth cell-to-cell movement
- Player animations
- Background music and sound effects
- Particle effects
- Object pooling

## Bonus Feature
- Dynamic board scaling: later levels contain more walls and enemies.

## How to Run
1. Open the project using Unity 6.3.
2. Open `Assets/Scenes/SampleScene.unity`.
3. Press Play.
4. Use the arrow keys to move.
5. Reach the exit to start the next level.
